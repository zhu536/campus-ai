## 剩余风险

- git `core.autocrlf` 可能在未来 checkout 时把 LF 转 CRLF，改变 CSV 文件哈希（内容不变）——属于仓库级配置问题，未越界修改 `.gitattributes`。
- CSV 里显式写了主键 id，后续导入器需要按列显式插入或忽略自增主键。
